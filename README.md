
# 🎵 Music Translator

A Python-based web application that translates
song lyrics into English.

## Features

- YouTube video information
- Available caption retrieval
- Automatic language identification
- English translation
- Original lyrics and translation side by side
- PDF generation

## Technologies

- Python
- Streamlit
- YouTube Transcript API
- Deep Translator
- ReportLab

## Installation

Clone the repository:

git clone (https://github.com/Harshaniesandjana/Music-Translator)

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Project structure

- app.py: Main web application
- youtube_handler.py: YouTube processing
- translator.py: Lyrics translation
- pdf_generator.py: PDF generation

## Disclaimer

Only process and reproduce lyrics and audio
that you are authorized to use.
